# Planning Poker (Client)

## Project setup

### Install dependencies
```
npm install
```

### Compiles and hot-reloads for development (Vite)
```
npm run dev
```

### Builds for production (outputs to dist/)
```
npm run build
```

### Lints (oxlint) and type-checks (vue-tsc)
```
npm run lint
npm run type-check
```

# Additional steps
- Copy the .env file from the [example folder](./example/) into the root of the client folder
- update the variables with the relevant values
